# AI 消息渲染清单

这份清单用于约束 Codex Web 的对话消息区。目标不是只把常见 Markdown 跑通，而是让 AI 回复、工具调用、长文本、流式生成、明暗主题和用户自定义主题都能稳定显示。

当前阶段先不更换渲染器。先按清单补齐当前 `react-markdown + remark-gfm` 能补的内容；如果某类能力需要更完整的生态支持，再单独评估是否引入插件或替换渲染管线。

## 基础文本

- [ ] 普通段落：保留自然换行，段落间距清晰，长单词、URL、本地路径不能撑破布局。
- [ ] 软换行和硬换行：用户可读，不把 AI 输出变成过密文本。
- [ ] 粗体、斜体、粗斜体：层级明显，但不能破坏正文灰度。
- [ ] 删除线：用于 GFM 删除线和任务完成状态。
- [ ] 行内代码：与正文有明确区别，不能像按钮或标签。
- [ ] 转义字符：反斜杠转义、实体字符和特殊符号显示正确。
- [ ] Emoji 和 CJK 混排：中文、英文、数字、标点、emoji 间距自然。

## 标题和结构

- [ ] H1-H6：字号逐级收敛，消息内标题不能像页面级 hero。
- [ ] 分割线：作为段落分隔，不抢视觉主导。
- [ ] 目录式长回答：多级标题在正文和右侧快捷跳转中都能被识别或预览。
- [ ] 折叠内容：`details/summary` 可读、可展开，并兼容明暗主题。

## 列表

- [ ] 无序列表：必须有清晰圆点或同等标记。
- [ ] 有序列表：必须显示 1、2、3 等编号。
- [ ] 嵌套列表：缩进层级稳定，不能和正文混成一块。
- [ ] 任务列表：未完成、已完成状态清楚；已完成项是否删除线由样式统一决定。
- [ ] 列表中的段落、代码、引用、表格：不能破坏列表缩进。

## 引用

- [ ] 普通 blockquote：必须有明确左侧标识或背景层次。
- [ ] 多段引用：多段内容仍然属于同一引用块。
- [ ] 嵌套引用：层级可读，不堆成噪声。
- [ ] 引用内列表、代码、链接：样式完整。

## 链接和路径

- [ ] 普通 URL：可点击、可复制、长链接不撑破消息区。
- [ ] Markdown 链接：文字和 title 正确。
- [ ] 本地 Windows 路径：`D:\...`、`C:\...`、带行号路径能被正确展示，不能误拆。
- [ ] 类 Unix 路径：`/home/...`、`./src/...`、`../...` 显示稳定。
- [ ] 文件引用：如果能安全映射到本机文件，再考虑点击打开；不能映射时只作为文本或普通链接展示。
- [ ] 锚点链接：同页锚点、脚注回跳不破坏 Web 应用路由。

## 代码

- [ ] 行内代码：只用于短 token，不吞掉周围标点。
- [ ] 围栏代码块：三个反引号必须渲染成真正的多行代码块。
- [ ] 语言标识符：显示语言名称，如 `ts`、`tsx`、`bash`、`powershell`。
- [ ] 语法高亮：明暗主题都要有可读配色。
- [ ] 行号：长代码块支持行号，行号不影响复制。
- [ ] 复制按钮：复制代码正文，不复制行号和 UI 文案。
- [ ] 自动换行策略：默认横向滚动，必要时支持切换换行。
- [ ] 超长代码块：有最大高度和内部滚动，不把整页撑坏。
- [ ] diff 代码块：新增、删除、上下文行有清楚颜色。
- [ ] 终端输出：ANSI 颜色需要剥离或安全渲染，不能污染页面。
- [ ] 未闭合围栏：流式生成中不能把后续所有内容错误吞进代码块。

## 表格

- [ ] GFM 表格：表头、单元格、边框、斑马纹或分隔清楚。
- [ ] 对齐语法：左、中、右对齐生效。
- [ ] 宽表格：容器内横向滚动，不撑破消息区。
- [ ] 单元格内行内代码、链接、换行：可读。
- [ ] 空单元格和长文本单元格：布局稳定。

## 脚注和引用标记

- [ ] 脚注定义：集中显示，字号和边界清楚。
- [ ] 脚注引用：上标链接可点击，不干扰正文行高。
- [ ] 脚注回跳：点击后回到引用位置。
- [ ] 多脚注：编号顺序稳定。

## HTML 混排

- [ ] 安全 HTML 白名单：只允许安全展示标签，禁止脚本、事件属性和危险 URL。
- [ ] `kbd`：键盘按键样式清楚。
- [ ] `sub` / `sup`：上下标生效。
- [ ] `mark`：高亮文本生效。
- [ ] `del` / `ins`：语义样式可读。
- [ ] `br`：换行有效。
- [ ] `details` / `summary`：可展开。
- [ ] 图片标签：如果允许渲染，必须限制尺寸和来源策略。
- [ ] HTML 表格：如果允许，样式与 Markdown 表格统一。

## 数学公式

- [ ] 行内公式：`$...$` 或等价语法显示稳定。
- [ ] 块级公式：`$$...$$` 居中或块级展示。
- [ ] 常见 LaTeX：分数、上下标、矩阵、希腊字母、求和积分。
- [ ] 未闭合公式：流式生成中降级为纯文本或轻量文本，不闪烁。
- [ ] 明暗主题：公式颜色跟随正文，背景不突兀。

## 图表和富内容

- [ ] Mermaid：流程图、时序图、状态图、甘特图可渲染。
- [ ] Mermaid 错误：语法错误时显示可读错误块，不让整条消息崩掉。
- [ ] Mermaid 主题：跟随明暗主题。
- [ ] SVG：默认不直接渲染不可信 SVG；如需支持必须走安全策略。
- [ ] 图片 Markdown：尺寸受控，支持点击预览时再做，不默认撑满。
- [ ] 附件预览：图片、文档、其他文件在用户消息中有稳定入口。

## Agent 工具调用

- [ ] 工具调用按真实时间顺序插入在 AI 回复中，不能把一轮里的所有工具调用粗暴合并成一块。
- [ ] 一轮回复内允许多段 AI 文本和多次工具调用交替出现。
- [ ] 工具调用默认折叠。
- [ ] 工具调用摘要：显示工具类型、命令或文件、状态、耗时。
- [ ] 工具调用详情：显示 cwd、命令、参数、输出、退出码、错误信息。
- [ ] 读取文件：显示文件路径、读取范围、是否成功。
- [ ] 写入/修改文件：显示文件路径、变更摘要、状态。
- [ ] Shell 命令：显示命令、工作目录、退出码、stdout/stderr。
- [ ] Web/浏览器操作：显示 URL、动作、结果摘要。
- [ ] 权限请求：显示请求内容、用户选择、时间。
- [ ] 失败工具调用：默认仍可展开，错误原因醒目但不刺眼。
- [ ] 历史恢复：刷新页面或换浏览器后，工具调用记录仍能恢复。
- [ ] 流式工具调用：进行中状态实时更新，结束后归档为完成或失败。

## 消息元信息

- [ ] 用户消息：显示时间、正文、附件，操作按钮常驻。
- [ ] AI 消息：显示模型、生成时间、总耗时、token 输入/输出、速度。
- [ ] 生成中 AI 消息：不显示重试/刷新等完成后操作，只显示轻量运行条和已用时。
- [ ] 完成后 AI 消息：显示复制、重新生成、更多等操作。
- [ ] token 不存在时：不伪造数据，隐藏对应字段。
- [ ] 多模型或多次模型调用：一轮用户请求只显示为一条完整 AI 回复，内部文本和工具调用按顺序组织。

## 流式生成策略

- [ ] 生成中使用轻量渲染：优先保证页面稳定和增量可读。
- [ ] 完成后使用完整渲染：再启用完整 Markdown、数学、图表、代码高亮等能力。
- [ ] 流式文本不能只显示最新 delta，必须累计显示完整已收到内容。
- [ ] 未闭合代码围栏：生成中降级为安全代码块或纯文本，完成后重新解析。
- [ ] 未闭合表格：生成中避免反复重排，完成后渲染成完整表格。
- [ ] 未闭合数学公式：生成中按文本显示，完成后渲染公式。
- [ ] 大段输出节流：避免每个 token 都触发昂贵完整渲染。
- [ ] 光标/typing 状态：只表示仍在生成，不遮挡正文。

## 性能

- [ ] 长对话：大量历史消息不能因为全量 Markdown 重渲染卡顿。
- [ ] 长消息：单条超长回复需要分段、懒渲染或可见区优化。
- [ ] 代码高亮：完成后执行，避免流式阶段重复高亮。
- [ ] Mermaid/数学：完成后执行，失败隔离到当前块。
- [ ] 图片和附件：懒加载，尺寸预留，避免布局跳动。
- [ ] 快速跳转：消息很多时降级或隐藏，不能拖慢滚动。

## 明暗主题和自定义主题

- [ ] 所有 Markdown 元素只使用 CSS 变量，不硬编码只适合亮色或暗色的颜色。
- [ ] 代码块主题同时支持亮色和暗色。
- [ ] 表格、引用、脚注、kbd、mark、任务列表在亮色和暗色下都要有足够对比度。
- [ ] Mermaid 主题跟随当前主题。
- [ ] 用户自定义主题 CSS 可以覆盖关键变量，不需要改组件代码。
- [ ] 主题切换时不需要刷新页面即可更新消息渲染样式。

## 可访问性和交互

- [ ] 操作按钮有 `aria-label` 和 title。
- [ ] 键盘可聚焦工具调用、复制按钮和折叠区域。
- [ ] 颜色不是唯一状态提示，失败/成功/进行中要有文字。
- [ ] 复制行为有短暂反馈。
- [ ] 链接新窗口打开时使用安全属性。

## 第一轮修复建议顺序

1. 补基础 Markdown CSS：引用、列表、有序列表、任务列表、脚注、kbd、sub/sup、表格、代码块。
2. 修代码块组件：真正区分 inline code 和 fenced code，补语言标识、复制、最大高度。
3. 补流式策略：生成中轻量渲染，完成后完整渲染。
4. 补安全 HTML 白名单：让 `kbd`、`sub`、`sup`、`mark`、`details` 等可用，同时阻断危险标签和属性。
5. 补数学公式：行内和块级公式。
6. 补 Mermaid：完成后渲染，错误可见。
7. 补工具调用渲染细节和历史恢复：按真实顺序持久化并恢复。
8. 做明暗主题验收：亮色、暗色、至少一个用户自定义主题都检查。
